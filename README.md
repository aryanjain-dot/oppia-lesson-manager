# Oppia Interactive Lesson Manager
A full-stack interactive lesson management system developed for the Oppia Open Source organization. This repository contains a React-based creator dashboard that allows educators to build, manage, and track student performance on interactive lessons. 

A professional creator portal developed for the Oppia ecosystem. This tool allows educators to build branching interactive lessons with real-time learner analytics.

## 🚀 Features
- **Creator Dashboard:** High-level metrics for lesson performance.
- **Interactive Blocks:** Support for MCQs and Fill-in-the-blanks.
- **Progress Tracking:** Real-time persistence of learner data.
- **Responsive Design:** Built with React and Tailwind CSS.

## 🛠️ Tech Stack
- **Frontend:** React.js
- **Styling:** Tailwind CSS
- **Icons:** Lucide-React
- **Charts:** Recharts
